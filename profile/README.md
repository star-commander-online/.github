# Star Commander Online

Star Commander Online is a browser MMO space game, where you can automate everything and anything with your own scripts.

## Projects

- **[starscript-core](https://github.com/star-commander-online/starscript-core)**: the small scripting language that powers in-game `.cmd` scripts. Includes the Go interpreter and a TypeScript WASM bridge.
- **[star-commander-online](https://github.com/star-commander-online/star-commander-online)**: the game client made with React (Vite) and SCSS.
- **[star-commander-server](https://github.com/star-commander-online/star-commander-server)**: the game server made Go *(Not available to the public...)*
